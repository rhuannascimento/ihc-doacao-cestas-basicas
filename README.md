# EasyDonation

Este projeto foi desenvolvido como parte da disciplina **Interação Humano-Computador (IHC)**, com o objetivo de aplicar técnicas de design centradas no usuário, criando uma experiência intuitiva e acessível.

## Tecnologias Utilizadas
- **Frontend Hospedado no Vercel:** Permite o acesso rápido e escalável ao sistema.
- **Firebase:** Utilizado para autenticação de usuários e armazenamento de dados.

## Funcionalidades
- Interface responsiva e amigável.
- Sistema de autenticação com diferentes roles de usuário.
- Roles pré-definidas para diferentes níveis de acesso:
  - **Administrador:** Acesso total para gerenciar usuários e configurações.
  - **Usuário Comum:** Permissões para acessar recursos específicos.
